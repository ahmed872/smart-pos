## Cashier System v1.1.0 — تحديث أمان وتجهيز للبيع التجاري

إصدار أمان واستقرار. مفيش تغيير في طريقة البيع أو التقارير اليومية.

### الأمان
- **صلاحيات حقيقية داخل البرنامج (Backend IPC authorization):** كل عمليات المدير (الموظفين، تعديل/حذف المنتجات، الإعدادات، النسخ الاحتياطي والاستعادة، التقارير) بقى يتم التحقق منها داخل البرنامج نفسه، مش مجرد إخفاء أزرار. الكاشير مش هيقدر ينفذها بأي طريقة.
- **قفل أدوات المطورين (DevTools/security hardening):** أدوات المطورين مقفولة في النسخة المثبتة، والبرنامج بيرفض أي محاولة لتوصيل debugger، ومفعّل عليه Electron fuses.
- **تشفير الأرقام السرية (Secure PIN hashing):** الأرقام السرية بتتخزن مشفرة (scrypt) ومش بتتخزن كنص صريح.
- **إزالة الحسابات الافتراضية (Removal of default credentials):** مفيش أي اسم مستخدم أو رقم سري افتراضي.
- **إعداد المدير عند أول تشغيل (First-run admin setup):** أول تشغيل على جهاز جديد بيطلب إنشاء حساب المدير.

### البيانات
- **نسخ احتياطي واستعادة آمنة (Safe backup/restore):** ملف الاستعادة بيتفحص بالكامل (سلامة الملف وتوافق الجداول والأعمدة) قبل استخدامه. قبل الاستعادة بتتحفظ نسخة أمان من البيانات الحالية، ولو البيانات الحالية تالفة بتتنقل لفولدر عزل بدل ما تتمسح. الملف التالف أو غير المتوافق بيترفض من غير ما البيانات الحالية تتغير.
- **تحقق صارم من البيانات (Strict data validation):** رفض الأسعار والتكلفة والمخزون والخصم والضريبة السالبة أو غير الصالحة. سعر الصنف ونسبة الضريبة وقت البيع بيتاخدوا من قاعدة البيانات.

### الجودة
- **بناء قابل للتكرار (Reproducible production builds):** البناء بيستخدم `npm ci` وإصدارات ثابتة من `package-lock.json`، والـrelease مش بيتعمل لو أي اختبار فشل.
- **اختبار على Windows (Windows verification/testing):** كل نسخة بتتبني وتتجرب تلقائيًا على Windows: اختبارات الكود، واختبار وظيفي كامل، وتثبيت وتشغيل وإلغاء تثبيت وإعادة تثبيت الـinstaller.

### ملاحظات التحديث من v1.0.0
- البيانات الحالية بتتنقل تلقائيًا، والموظفين بيدخلوا بنفس أرقامهم السرية.
- أي حساب لسه على رقم سري افتراضي قديم هيُطلب منه تغييره عند أول دخول.
- الرجوع لنسخة v1.0.0 بعد التحديث غير مدعوم.
- الـinstaller غير موقّع رقميًا، فممكن Windows SmartScreen يظهر تحذير عند التثبيت.
